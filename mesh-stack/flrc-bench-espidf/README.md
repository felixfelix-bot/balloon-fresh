# FLRC Bench (ESP-IDF)

ESP32-C3 FLRC/LoRa benchmark firmware using RadioLib + LR2021.

## PRBS15 BER Test Pattern — Reference Implementation

The C3 (ESP32-C3) is the **reference implementation** of the PRBS15 BER test
pattern used across both balloon benchmark rigs. The E80 (STM32) rig now uses
an identical algorithm, ported from this codebase.

### Reference Files

- **C3 (this repo):** `main/prbs.cpp`, `main/prbs.h`
- **E80 (STM32):** `firmware/e80-stm32-bench/src/prbs.c`, `prbs.h` in `balloon-e80bench`
- **Cross-platform tests:** `tests/test_prbs15_cross.py` (11 tests, all passing)
- **Verification marker:** `PRBS15-VERIFIED.txt`

### Algorithm Specification

**Polynomial:** x^15 + x^14 + 1 (Galois LFSR, taps at bits 14 and 13)

**Seed derivation:**
```c
uint16_t state = (uint16_t)(seq ^ 0x5A5A) | 1;
```

**LFSR direction:** Left-shift (Galois)
```
newbit = (state >> 14) XOR (state >> 13)
state  = ((state << 1) | newbit) & 0x7FFF
```

**Byte assembly:** MSB-first — each byte is assembled from 8 consecutive LFSR
output bits, most-significant bit first.

**Payload format:** 4-byte big-endian sequence number header + PRBS15 fill.

### Cross-Platform Verification

The file `tests/test_prbs15_cross.py` contains 11 tests that reimplement the
PRBS15 algorithm in pure Python and validate it against known test vectors.
This ensures both the C3 and E80 C implementations produce identical output
for any given seed, enabling direct cross-rig BER comparison.

### Compatibility

| Platform | Repo | Implementation | Status |
|----------|------|-----------------|--------|
| C3 (ESP32-C3) | balloon-fresh | `main/prbs.cpp` | Reference |
| E80 (STM32) | balloon-e80bench | `src/prbs.c` | Ported, matches C3 |

Both implementations share the same polynomial, seed derivation, LFSR shift
direction, byte assembly order, and payload format. A packet generated by
one rig can be verified by the other with no modification.

## 0. Why this kit exists in our lab

Felix bought 2× E80-900MBL-02 so LR2021 performance can be evaluated **before** the
custom v_c3_flight PCB (NiceRF LoRa2021F33-2G4, 2 W PA) is back from fab (~2–3 weeks;
see PCB-LESSONS-LEARNED-2026-08-05 for fab-readiness caveats).

**What it is:** EByte eval motherboard (STM32F103C8T6 + CH340 USB-UART) + E80-900M2212S
module (Semtech LR2021, +22 dBm sub-GHz / +12 dBm 2.4 GHz, dual SMA). Host talks UART
115200 8N1 hex command protocol; the STM32 owns the radio SPI (9 MHz, Semtech LR20xx
driver v1.3.1 with all 12 modems linked — LoRa, FLRC, LR-FHSS, BLE, RTToF, …).

**Confirmed by demo source read:** silicon is genuine LR2021, dual-band, same chip
family our custom boards drive via raw 2-byte opcode SPI (ADR-020).

**Ports on this box:** /dev/ttyUSB3 + /dev/ttyUSB4 (CH340, appeared 2026-08-15 16:55).
NOT in balloon-board-lock system → no mutex contention with other tracks, no flash
approval needed (stock firmware, no flashing planned).

## 1. What the kit CAN and CANNOT do for us

| Capability | E80-900MBL-02 | Our RP2040/ESP32 boards |
|---|---|---|
| LoRa sub-GHz (SF5–SF12, BW125/203/500) | ✅ via C2 one-shot config | ✅ V4 sweep, proven |
| LoRa 2.4 GHz | ✅ (C3 presets) | ✅ (20 s guard band) |
| FLRC | ❌ driver linked, NOT exposed by UART commands | ✅ LF-650 best result 0.5 % PER |
| Max throughput | ~LoRa ceiling, UART 115200 host cap | 1377 kbps E2E, 1797 TX-only (RP2040) |
| TX power | +22 dBm LF / +12 dBm HF, 1 dB steps, factory PA cal | 12.5 dBm firmware, +30 dBm F33 never exercised |
| RSSI/SNR per packet | ❌ discarded in demo fw (PER only by counting) | ✅ per-packet RSSI + BER + GPS |
| Antenna / matching | factory-matched SMA (reference quality) | custom (unquantified vs reference) |
| Boot-to-test | minutes, zero flashing | flash queue + locks + firmware build |

**Conclusion:** E80 = turnkey **reference link + range mule** for the LF band (and 2.4 GHz
LoRa), starting today. Throughput maximization stays on OUR boards (E80 host path caps
far below our SPI work). The two together let us quantify our custom implementation
against a commercial reference — the thing we could never do before.

## 2. GOAL A — Maximum desk throughput out of LR2021

A0. **E80 bring-up (blocking: antenna confirmation, §4 Q1)**
    - Verify both modules alive over UART; set EU-legal frequency (868 MHz if the
      900M SKU filter allows — empirically check; else 869.525 or fall back to
      shielded desk test at 915 with note) and LOW power first (C2 power byte min).
    - Transparent-mode loop test ttyUSB3→ttyUSB4, 255 B frames, count PER at 1 m.
    - Deliverable: `tools/e80_ctl.py` (config + test harness), bench log.

A1. **Bench re-verify V4 pair (our boards)** — single-batch SPI port + nullptr fix
    compiled but NEVER flashed together. Flash F242D + repaired TX via make targets,
    60 s FLRC-650 sustained → confirm 1377 kbps baseline. (Flash-queue + locks apply.)

A2. **Test ESP32-C3 GDMA build** (feat/esp32-spi-gdma, 40 MHz SPI + batch DMA,
    BUILT-NOT-TESTED) on c3-a/c3-b. Same sustained test. Target: >1377 kbps E2E.

A3. **Push FLRC-1300/2600 LF** with GDMA host path (SPI clock was the bottleneck —
    LA-measured 10.35 MHz = 67 % of air rate on RP2040). Success = first working
    >1.3 Mbps FLRC link on our hardware.

A4. **Cross-check against E80 reference** — C2-config E80 pair to fastest LoRa
    (SF5/BW500) for chip-max-LoRa sanity number; mine E80_DEMO's Semtech v1.3.1
    driver (FLRC init sequence, PA tables incl. HF TODO table) against our ADR-020
    implementation for any correctness/perf deltas.

A5. **HF 2.4 GHz FLRC** (1300/2600): retry at quietest WiFi time (28 networks killed
    it before). Optional, after LF milestones.

## 3. GOAL B — Range characterization at various distances

Methodology (both pairs): N=1000 packets × 255 B per (distance, mode), PER from RX
count, RSSI/SNR logged where available (our boards only), GPS track for geometry.
Distances: 1 m / 10 m / 50 m / 100 m / 250 m / 500 m / 1 km / 2 km / 5 km+ LOS.
Modes: SF7 / SF9 / SF12 @ BW125 (sub-GHz), + FLRC-650 on our boards.

B1. **E80 pair walk test (can start immediately after A0)**
    - RX module + this box on desk; TX module + T470 (battery) walked/cycled away.
    - Controller script sends paced frames, RX logs arrivals + timestamps.
    - PA both sides +22 dBm (skip ≤10 m or drop power byte to avoid overload).
    - Regulatory: EU 868 MHz SRD band + duty cycle respected; 915 MHz TX not legal
      in EU — freq decision in A0 matters.
    - Bonus: C1 02 CW mode for interference/path loss spot checks if SDR available.

B2. **Custom boards walk test (after A1)** — V4 interleave sweep, GPS-embedded,
    extends existing 5.7 km results with PA=ON at ≥100 m and FLRC range curves.

B3. **Same-day cross-pair comparison** — E80 vs custom at 2–3 fixed distances:
    quantifies our antenna/PA/board implementation quality vs commercial reference.
    THE key deliverable for the custom PCB decision matrix.

B4. **Deliverables:** `docs/RANGE-REPORT-E80-vs-custom-<date>.md` + log-scale PER
    curves per mode, range table per SF, RSSI-vs-distance fits.

## Method / bounds
`search.py` searches a fixed absolute 0.05 mm grid in x=6..12, y=39..46, with 3 MISO waypoints at x=8.35/7.95/7.55, y=42.50; 180-second alarm per trial. Exact polygon segment checks gate the grid path and greedy simplification. Track width 0.20 mm, conservative clearance screening 0.2002 mm. Off-pad via centers screened against foreign copper on every enabled copper layer and every pad including own-net pads; final native DRC checks holes, clearance and actual written geometry. Candidate via grid 0.10 mm in x=8..10,y=40.5..44; at most 40 closest sites tested per pad. No separate blind/buried-via or remote multilayer routing pass. Filled zones are not fixed obstacles: all baseline/candidate zones were actually refilled using KiCad 9.0.9 ZONE_FILLER before grading.

Trial 01/02: 16/15 geometrically screened power-via sites, no stub path found. Trial 03: power escape succeeds; 31 screened ground-via sites, no stub found. Sequential search is a bounded coupled attempt, not a proof of joint infeasibility. Ground is not silently assumed solved. Search stops after three topologies; no further candidate family is authorized by this pass.

Positive open-region and negative solid-wall search controls pass (`constraints.json`). Initial implementation defects were repaired before results: pcbnew Remove ownership caused crashes (use Delete); zero-length endpoint LineStrings falsely rejected grid-aligned endpoints (use Point). Preliminary failed outputs were overwritten by corrected runs; none are acceptance evidence. UUIDs generated by pcbnew may differ when rerunning.

## Decision / next constraint
Preserve trial 03 as a **rejected joint-solution milestone**, not a canonical repair. Left rerouting and a legal power-layer transition are demonstrated; delivery to the required power component and a legal ground transition remain unproved. A future pass must route from the escaped power component to the pinned U1.2 component while recovering C10.2 access jointly; may need a different MISO topology, finer escape grid, or an explicitly scoped additional movable object. No impossibility claim.

## Reproduce
Run `/usr/bin/python3 search.py N` for N=1,2,3 from this directory (requires pcbnew, numpy, shapely), then `/usr/bin/python3 audit-tools/audit.py trial-03/board.kicad_pcb trial-03/audit --label trial-03`. Refilling baseline: load input board with pcbnew, `ZONE_FILLER(board).Fill(board.Zones())`, SaveBoard into paired baseline directory. Render tool additionally requires rsvg-convert. Native reports and graphs are retained for review.

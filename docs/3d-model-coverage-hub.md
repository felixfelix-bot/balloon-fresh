## 1. Why this document exists

A render of this board was **misleading twice**, and each time the operator
(or a vision model) correctly read a defect that was in the render, not the
reader:

1. **Empty render.** Every model reference pointed at `${KICAD9_3DMODEL_DIR}/…`
   with the library uninstalled: 0 of 32 references resolved, and a vision
   model reported components that were only silkscreen text.
2. **2.54x oversize models.** The repo-local models that replaced them were
   authored in raw millimetres, but KiCad reads a VRML coordinate as
   **2.54 mm per unit** - so the 78.55 x 38.90 x 0.21 mm solar cell rendered
   as a 199.5 x 98.8 x 0.53 mm grey slab and the supercap placeholder as a
   25.7 x 25.7 x 17.8 mm thick can.  The operator's "grey slabs all over the
   place" and "some grey things are really thick" was a CORRECT reading.

The cure: this table states, for every footprint, what is drawn and where
every dimension came from.  **Never read a render without it.**

## 2. The cell face fix (ADR-055 D6)

`PVA1`/`PVA2` are DNP illustrative array cells.  They were first emitted on
`B.Cu`; **ADR-055 D6 states "The hub-array cells are mounted on the UPPER
face of the board"**, and with the hub plane horizontal (D1) the upper face
is the sun-facing side (the array is "effectively single-face", §D2).
The cells are now on `F.Cu` (operator-approved 2026-10-08).  Their model is
the **two-material IndexedFaceSet cell** ported from the wing generator - a
dark-blue silicon face (diffuseColor 0.09 0.10 0.42) over a light-grey frame
(diffuseColor 0.55 0.56 0.60) - in correct VRML units (mm / 2.54).

## 3. Render environment

**The render now REQUIRES** `export KICAD9_3DMODEL_DIR=/usr/share/kicad/3dmodels`
(the `kicad-packages3d 9.0.7-1` package, 4.6 GB, IS installed on this host).
Without it the 20 library-modelled footprints below silently vanish and the
render regresses to the empty-board confabulation.

## 8. Reproduce

```sh
python3 scripts/gen_3d_models.py            # regenerate the committed custom models
python3 scripts/gen_3d_models.py --check    # fail if any model drifts
/usr/bin/python3.14 tracker/hardware/build_hub_board_v9.py --publish   # rebuild the board
python3 scripts/3d_model_coverage_report.py  # regenerate this document
export KICAD9_3DMODEL_DIR=/usr/share/kicad/3dmodels   # REQUIRED for the render
kicad-cli pcb render --output out.png --side top --quality high \
    --width 1800 --height 1400 tracker/hardware/hub_board_v9.kicad_pcb
```

> Standard parts use the REAL KiCad library (`${KICAD9_3DMODEL_DIR}`); custom
> parts the library will never carry are committed under
> `tracker/hardware/footprints/3dmodels/` in correct VRML units (mm / 2.54).

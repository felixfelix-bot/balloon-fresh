## 1. Context

### 1.1 The string, and what a single cracked cell does to it

ADR-006 / ADR-049 / ADR-051 §1.1 fix the array as **4 wings × 3 LARGE cells = 12 cells in ONE
series string**, wired through the hub:

```
stack_top  = W1_SOLAR_P   -> BAT54 -> supercap bank -> TPS7A02 (ADR-006)
             W1_SOLAR_N —(hub link)— W2_SOLAR_P
             W2_SOLAR_N —(hub link)— W3_SOLAR_P
             W3_SOLAR_N —(hub link)— W4_SOLAR_P
stack_bot  = W4_SOLAR_N   -> GND plane
```

Verified numbers (all cited in ADR-051 §1.1/§1.4 and its sources):

| Quantity | Value | Source |
|---|---|---|
| Cells in series | **12** (4 wings × 3) | ADR-006, ADR-049, ADR-051 §1.1 |
| String voltage, nominal | **6.0 V** | ADR-006; ADR-049 §Decision |
| String current, nominal | **1.2 A** | ADR-049 (the LARGE cell is ~0.5 V, ~1.2 A) |
| Peak power | **7.2 W** (6.0 V × 1.2 A) | ADR-049; ADR-051 §2.4 |
| Voltage step per wing (cut or bypass) | **1.5 V** | ADR-051 §1.1 |
| Cut ladder | 6.0 / 4.5 / 3.0 / 1.5 V | ADR-051 §1.1, §2.4 |
| Cold open-circuit stack voltage | **≈9.58 V at −60 °C** | ADR-050 §3.2, quoted ADR-051 §2.7 |

**A series string is only as good as its worst cell.** With no bypass, any ONE of the 12 cells that
(a) goes **open**, or (b) is **reverse-stressed** by the other eleven (shaded, or cracked to a
resistance), takes the **whole 6.0 V string** with it. The array is a single point of failure with
12 identical failure sites, and — per ADR-052 — the failure mode is a **thermal-cycling crack**,
i.e. a mechanism that will occur in flight rather than an improbable accident.

### 1.2 The bypass diode, and what it buys

A Schottky **across** the cell (or the group), **cathode to the group's positive terminal**, gives
the string current a path *around* the failing cell. The rest of the string continues to conduct:

```
without bypass : 1 open cell  -> the whole 6.0 V string is dead
with    bypass : 1 open cell  -> the diode conducts; the string continues at one cell (or one
                                 group) less voltage
```

This is the operator's exact framing: *"one cracked cell costs one cell"* rather than the whole
array. The hub-side half of this already exists as a paper provision — see §1.5.

### 1.3 THE SIZING RULE THAT MATTERS: the bypass path is a PERMANENT CONTINUOUS path

The reason the current `BAT54` provision is wrong is not a transient spike. It is the **duty cycle**:

- **After a failure**, a bypassed cell stays bypassed **for the rest of the flight**. The remaining
  cells drive **the full string current, continuously**, through that one diode. ADR-051 §2.4
  decision 4.3 states this for the **post-cut** case; it is equally true for an **open** cell and,
  for the duration of the shading, for a **shaded** cell (§1.4).
- **The current is the full string current, not the cell's share.** When a cell is bypassed, all the
  other cells' current is forced through the diode. At the nameplate that is **1.2 A** (ADR-049).
- **The diode must also hold off the string's reverse voltage** when it is *not* conducting. The
  worst case is the **cold open-circuit stack voltage ≈9.58 V at −60 °C** (ADR-050 §3.2): the array
  runs cold and the voltage rises, so the reverse rating must clear ≈9.58 V at the worst
  temperature, not 6.0 V at 25 °C.

Therefore **the bypass diode is a continuous-duty part, not a transient protection part.** The
requirement is **≥2 A continuous / ≥40 V** — margin on both axes over 1.2 A and 9.58 V, and the
figure ADR-049 and ADR-051 §2.7 already name.

**This rule is why the BAT54 is DISQUALIFIED — twice over.** The part currently specified for
`D_BP1…D_BP4` is a **BAT54: 200 mA / 30 V** (`build_flight_sch.py` lines 1011–1027, value
`"BAT54 (DNP)"`; socket spec §5; ADR-046 §2.3).

- It is **6× under-rated on current** even *before* any failure: 200 mA against a **1.2 A** array
  (ADR-049 clause 1: *"BAT54 family = 200 mA / 30 V against the accepted 0.4 A array — undersized
  **before** any change"* — the v9 array is 1.2 A, so 6× short).
- It is **under-rated on voltage**: 30 V against a **≈9.58 V** cold open-circuit stack — that one
  clears at −60 °C, but with only ≈3.1× margin on a part whose family is the 200 mA class, and the
  socket-spec rationale (ADR-046 §2.3) was written for a *shading* transient, not a permanent path.

Hence the target is a **≥2 A / 40 V Schottky** (ADR-049; ADR-051 §2.7 names **SS24** or
**PMEG4020ER** class, and excludes **SOD-323** because it cannot carry 2 A). §1.6 prices real parts.

### 1.4 The three failure modes — all covered by the SAME diode

The operator's question was about a **cracked** cell, but the same diode covers three distinct
failure modes. All three are stated here so the provision is not read as only an open-circuit guard.

1. **A cell goes OPEN.** The crack severs the cell's conductor. **Without a bypass the string is
   broken and all 12 cells are lost.** With the bypass, the diode conducts and the other 11 cells
   continue; the string loses one cell (or one group). *This is the mode the operator asked about.*
2. **A cell goes SHORTED (or cracks to a low resistance).** A hard short does **not** itself block
   the string — a zero-volt element still conducts, so the string continues at 0.5 V less. The
   dangerous variant is a **resistive / partially cracked** cell: the other eleven cells
   reverse-drive it, which is exactly the mechanism the socket spec §5 and ADR-046 §2.3 name —
   *"without it one shaded wing collapses and **reverse-stresses** the whole 6.0 V series string"*.
   The bypass diode gives that reverse current a **defined path** (through the diode, clamped to its
   forward drop) instead of forcing it through the failing cell. **A series string without a bypass
   is worse than one with it: the reverse-stressed cell has nowhere to put the current, so it either
   burns open — degrading into mode 1 and killing the string — or drags the string voltage down.**
   With the bypass the damage is contained to the one cell.
3. **A cell is merely SHADED.** Shading collapses the cell's own output; it becomes a load and the
   illuminated cells reverse-bias it. The bypass diode conducts **for the duration of the shading**.
   A shroud, a tumbling attitude or the envelope covering one wing is a shading event that can last
   minutes to hours — i.e. the *same* continuous-current duty as mode 1 (§1.3). This is the mode
   `docs/analysis/pico-balloon-solar-survey.md` §7 item 5 records as the community's reason for the
   diode: KS4VA uses *"three SMD Schottky diodes … to 'steer' or isolate the dark solar panels from
   the illuminated one"*; NIBBB uses `1N5817` ×3.

**One diode, one rating rule, three failure modes.** No mode needs a different part, a second
component, or a firmware action — the diode is passive.

### 1.5 What already exists: the per-INTERFACE provision is the per-GROUP case

The hub board **already carries four bypass-diode provisions**, one per wing interface, currently
**DNP** — verified in all three places that matter:

| Where | Content |
|---|---|
| `build_flight_sch.py` (authoritative) | `D_BP1…D_BP4`, `Device:D_Schottky`, value `"BAT54 (DNP)"`, footprint `Diode_SMD:D_SOD-323`, each with the polarity note *"cathode to `W<n>_SOLAR_P`, anode to `W<n>_SOLAR_N`"* (lines 1011–1027) |
| `docs/WING-TO-HUB-SOCKET-SPEC.md` §5 | *"Per interface, one Schottky bypass diode provision across `W<n>_SOLAR_P` ↔ `W<n>_SOLAR_N`, cathode to `W<n>_SOLAR_P` … DNP on the first prototype build"* |
| `v9_flight.net` (committed) | `D_BP1` pin 1 (K) on `W1_SOLAR_P`, pin 2 (A) on `W1_SOLAR_N`; `D_BP2` K on `W1_SOLAR_N`(=`W2_SOLAR_P`), A on `W2_SOLAR_N`; and so on to `D_BP4` A on `GND` — each spanning exactly one **wing's** 3-cell series group |

**So the per-GROUP-of-3 topology is already the designed-in provision** — one diode per wing = one
diode across 3 cells. What ADR-051 §2.4 decision 4.2 adds is that the diodes must be **populated,
not DNP, on any cutter flight** (a cut leaves the socket lands open, so the diode is the cut
mechanism's other half), and §2.7 re-rates them to ≥2 A / 40 V. **This record's job is to price the
per-cell alternative against that baseline and to gate the presence of the diode mechanically.**

### 1.6 The grouping trade — priced with real datasheet masses

Two topologies, both with the same ≥2 A / 40 V requirement (§1.3 — *every* bypass diode carries the
full string current, whatever the group size, so the per-cell option cannot use a smaller part):

| Topology | Diodes | Granularity | Array lost per single failure | Diode mass |
|---|---|---|---|---|
| **Per-GROUP of 3** (one per wing) | **4** (`D_BP1…D_BP4`) | one wing | **3 of 12 cells = 1/4** (1.8 W of 7.2 W peak) | **4 × 64 mg = 256 mg** |
| **Per-CELL** | **12** | one cell | **1 of 12 cells = 1/12** (0.60 W of 7.2 W peak) | **12 × 64 mg = 768 mg** |

**Mass figures are VERIFIED against real vendor datasheets, fetched 2026-10-07** — not the repo's
own estimates (which is why they differ from them):

| Part | Class | Package | Mass (datasheet) | Source |
|---|---|---|---|---|
| **Diodes Inc B240/A** | **2.0 A, 40 V** Schottky | **SMA** | **0.064 g = 64 mg** | `https://www.diodes.com/assets/Datasheets/ds13004.pdf` — *"Weight: SMA 0.064 grams (Approximate)"* |
| Diodes Inc B240/A | 2.0 A, 40 V Schottky | SMB | 0.093 g = 93 mg | same datasheet — *"SMB 0.093 grams (Approximate)"* |
| Diodes Inc BAV16W/1N4148W | SOD-123 (signal) | SOD-123 | 0.01 g = 10 mg | `https://www.diodes.com/assets/Datasheets/ds30086.pdf` — *"Weight: 0.01 grams (Approximate)"* |
| Diodes Inc SK12–SK16 | 1 A Schottky | SMA | 0.093 g = 93 mg | `https://www.diodes.com/assets/Datasheets/ds13003.pdf` — *"Approx. Weight: 0.093 grams"* |
| Nexperia **PMEG4020ER** | **2.0 A, 40 V** Schottky | SOD123W | **not stated in the datasheet** | `https://assets.nexperia.com/documents/data-sheet/PMEG4020ER.pdf` (product data sheet, 1 January 2023) — carries a package-outline figure but **no mass** → **TODO(unverified)** |

**The arithmetic, stated plainly (using the ≥2 A / 40 V part actually needed, B240 in SMA at 64 mg):**

```
per-cell  : 12 x 64 mg = 768 mg = 0.768 g
per-group :  4 x 64 mg = 256 mg = 0.256 g
delta     :  8 x 64 mg = 512 mg = 0.512 g        <-- THE NUMBER THAT DECIDES IT
```

**The deciding number is 512 mg** — the extra mass of going from 4 diodes to 12. Two independent
scales put it in context:

- The whole four-wing array is **12.85 g** (ADR-049; ADR-051 §1.5). **512 mg is 4.0 % of the entire
  array** — to buy a finer failure granularity.
- The payload is **mass-bound** and ADR-051 already adds **≈14–20 g** of hub array, harvester and
  cutters to close the cut ladder. A further 0.5 g for redundancy granularity competes with that.

**And the granularity being bought does not change whether the array still charges.** The array's
*requirement* is **0.388 W average** (ADR-050 §1/§4; ADR-051 §1.4). Losing a whole group (3 cells)
leaves **75 % of the 7.2 W peak = 5.4 W** — more than **13× the average requirement**, and, on the
voltage axis, a group bypass reproduces **exactly the cut ladder's 1.5 V step** (ADR-051 §1.1), so
the string sits at 4.5 V and stays above the converter's 2.5 V floor. **Per-group therefore already
keeps the vehicle charging.** Per-cell's finer granularity improves a number (peak power) that is
not the binding constraint.

> `D_BP1…D_BP4` provision, populate it (§2 item 4) and re-rate it to ≥2 A / 40 V (§2 item 2).**
> The deciding number is the **+512 mg** that per-cell costs for a granularity improvement
> (1/4 → 1/12) that the 0.388 W average budget does not need. **This recommendation is marked
> revisable pending the `analysis/array-topology-fault-tolerance` topology study** (§"Open items"
> 4): if that study finds the array must tolerate *multiple simultaneous* cell cracks, or that the
> cut ladder's premise is superseded, the per-cell option re-opens — the extra 8 diodes cost only
> 512 mg and the `bypass_diode_check.py` gate already checks both topologies.

### 1.7 Placement consequence — the diodes live on the WING boards

**A diode "across a cell" or "across a group of 3" is electrically across that cell's or group's
terminals, and those terminals are on the WING board, not the hub.** The hub sees only the wing's
`solar_P` / `solar_N` lands through the 4-land socket (ADR-046 §2.1, ADR-048). So:

- **Per-group (recommended):** the diode can sit **either** on the hub (across the wing's
  `W<n>_SOLAR_P` ↔ `W<n>_SOLAR_N` lands — which is where `D_BP1…D_BP4` already are, and what ADR-051
  §2.4.2 mandates) **or** on the wing board itself. The hub placement is the one already drawn.
- **Per-cell:** each diode must sit **on the wing board**, across one cell's terminals, because the
  individual cell terminals are not brought out to the hub. This is a **wing-board change** (12
  diodes over 4 wings = 3 per wing board), and it is only reachable through the wing respin of §2
  item 6.
- **Whatever hub array exists (ADR-051 §2.2) needs its own per-cell or per-group diodes on the hub**,
  since those cells are hub-mounted.

Stated plainly: **per-cell diodes are a wing-board (and hub-array) change; the per-group diodes, in
the recommended topology, are where they are already drawn.**

### 1.8 THE POINT THAT MAKES THIS CHEAP: the v9 wing must be RE-SPUN ANYWAY

**The v9 wing board has to be re-spun regardless of this record, so the bypass diodes add no new
respin.** ADR-051 §2.6 and its "Open items" 9 establish it, and this record relies on it:

- The wing tab's **pin 3 (`W<n>_RF` / `RF_FEED`) is a copper land with NO net** on v9 — verified:
  the four `RF_FEED` lands appear in no `(net …)` in the committed `v9_flight.net`, and ADR-046 §2.4
  records it as *"a copper land that is left electrically unconnected (a provision)"*.
- ADR-051 §2.6 re-uses pin 3 as the **per-wing `CUT_SENSE_W<n>` line** for the cut ladder. **For that
  sense line to measure anything, the WING must net its `RF_FEED` land into the cut loop's return** —
  a continuity measurement to a pad that floats on **both** ends proves nothing. *"Re-using pin 3 is
  free at the connector; it is not free at the wing."*
- Therefore **a wing re-spin is already required**, and it is required **once**.

**This record forbids a second wing respin (see §2 item 6).** All wing changes must be consolidated
into **one** new wing revision: the bypass diodes (if per-cell), the `RF_FEED` cut-sense provision,
and the diode re-rate. A separate future wing change for the bypass diodes would mean paying the
wing respin cost **twice**, and is explicitly **wasted work**.

### 1.9 What is NOT in the repo

- **No per-cell diode exists anywhere** — the only bypass provisions are the four per-interface
  `D_BP1…D_BP4` (per-wing). A per-cell topology is a paper option.
- **No measured continuous rating** for any chosen part at altitude/cold temperature: the diode's
  `I_F` falls with temperature, and the repo has no such figure (ADR-051 §2.7 already flags this).
- **No flight measurement of a cracked cell's actual behaviour** — the crack is *observed*
  (ADR-052) but its electrical signature (open vs. resistive) is not characterised in the repo.
- **No hub-array cells in the committed schematic** (ADR-051 §2.1 is not yet implemented; its own
  checker returns `UNDETERMINED (exit 2)` on the shipped netlist). So a per-cell check of hub cells
  is vacuous on the current netlist (§2 item 8).

## 2. Decision

### 2.1 Decision item 1 — every cell, or every series group, in the solar path MUST have a bypass diode across it

**The bypass diode is a REQUIREMENT of the solar path, not an option.** For every cell **or** every
series group of cells in a solar series string, there must be a Schottky diode across that cell /
group, **cathode to the group's positive terminal, anode to its negative terminal**, so that an
open, shorted or shaded cell does not open or reverse-stress the whole string.

- The **recommended grouping is per-GROUP of 3** (one diode per wing = the existing
  `D_BP1…D_BP4`), for the reason in §1.6 and with the 512 mg number stated there.
- **Per-cell (12 diodes)** is an admissible alternative, not a requirement, and is marked revisable.
- **No solar cell and no series group may ship without a diode across it.** This is the invariant
  `scripts/bypass_diode_check.py` enforces (§2 item 8).

### 2.2 Decision item 2 — the sizing rule is PERMANENT CONTINUOUS CURRENT: ≥2 A / ≥40 V, and the BAT54 is DISQUALIFIED

**A bypass diode must be rated to carry the FULL string current CONTINUOUSLY and to hold off the
string's reverse voltage.** The bypass path is not a transient: after a failure or a cut, the
remaining cells drive the full string current through that diode for the rest of the flight, and
during shading for the duration of the shading (§1.3).

1. **Continuous-current requirement: 1.2 A nominal, sized with margin to ≥2 A** (ADR-049; ADR-051
   §2.7). The current through a bypassed position is the *whole string's* current, not the cell's
   share — so the requirement does **not** shrink for the per-cell topology.
2. **Reverse-voltage requirement: ≥40 V**, sized against the **≈9.58 V cold open-circuit stack**
   (ADR-050 §3.2) with margin for the cold-temperature voltage rise.
3. **The BAT54 (200 mA / 30 V) is DISQUALIFIED and may not be fitted in any bypass position.** It is
   **6× under-rated on current** against the 1.2 A array *before* any failure, and was chosen
   (socket spec §5) for a *shading transient*, which the permanent-continuous rule overrides.
4. **Consequence: the package and land change.** SOD-323 cannot carry 2 A (ADR-051 §2.7); the land
   must move to an **SMA/SMB or leadless 2 A-class footprint**. `TODO(unverified)`: the chosen
   part's temperature-derated continuous current at altitude (ADR-051 §2.7 already carries this).

### 2.3 Decision item 3 — three failure modes, one diode

**One diode covers all three modes** (§1.4); no mode requires a different part, a second component
or a firmware action:

1. **OPEN cell** — the diode conducts; the string continues at one cell/group less. (Without it, all
   12 cells are lost.)
2. **SHORTED / cracked-to-resistive cell** — the diode gives the reverse current a defined path and
   clamps the reverse bias, so the failure is contained to the one cell instead of cascading into an
   open and killing the string. **A series string without a bypass is worse than one with it** here:
   the reverse-stressed cell has nowhere to put the current.
3. **SHADED cell** — the diode conducts for the duration of the shading, which is the *same*
   continuous-current duty as a failure (hence the §2.2 rating).

### 2.4 Decision item 4 — the grouping is an OPEN knob with a priced trade; recommendation is per-GROUP, revisable

| | Per-CELL | Per-GROUP of 3 |
|---|---|---|
| Diodes | **12** | **4** |
| Max tolerance | a single failure costs **≈1/12** of the array | a single failure costs **≈1/4** of the array |
| Diode mass (B240 SMA, 64 mg, datasheet) | **768 mg** | **256 mg** |
| Extra mass over per-group | — | **−512 mg** |
| Where the diodes sit | **wing boards** (cell terminals are not on the hub) | hub (existing `D_BP1…D_BP4`) or wing |
| Already designed in? | No | **Yes** (per-interface provision, ADR-046 §2.3 / socket spec §5) |

**Recommendation: per-GROUP of 3 — keep `D_BP1…D_BP4`, populate them, re-rate to ≥2 A / 40 V.**
The **number that decides it is the +512 mg** (8 extra diodes at 64 mg) that per-cell costs; the
granularity it buys (1/4 → 1/12) does not change whether the array charges, because losing a group
still leaves 5.4 W against a 0.388 W requirement (§1.6). **This recommendation is revisable** and is
revisable *pending the topology study* in §"Open items" 4 — nothing here forecloses the per-cell
option, and the checker (§2 item 8) checks both.

### 2.5 Decision item 5 — the diodes live on the WING boards (and on the hub array)

Stated plainly (§1.7): **per-cell diodes are a wing-board change** (the cell terminals are not
brought out to the hub); the **recommended per-group diodes are already drawn on the hub** and may
alternatively be placed on the wing; and **any hub-mounted array (ADR-051 §2.2) needs its own
diodes on the hub**.

### 2.6 Decision item 6 — the wing changes are consolidated into ONE respin; a second respin is FORBIDDEN

**The v9 wing must be re-spun anyway** (§1.8, ADR-051 §2.6), because netting `RF_FEED` for the
cut-sense line is a **wing** change. **Therefore all wing changes for this record are consolidated
into that single respin**, which must carry, together:

1. the bypass diodes (**if** the per-cell topology is chosen — 3 per wing board);
2. the `RF_FEED` / `CUT_SENSE_W<n>` cut-sense provision (ADR-051 §2.6);
3. the diode re-rate consequence (`≥2 A / 40 V`, its land/package change) where the diode is
   wing-mounted.

**An explicit prohibition: no second wing respin for the bypass diodes.** A wing revision that
carried the cut-sense provision but *not* the bypass diodes, followed by a later wing revision for
the diodes, would pay the wing respin cost **twice** and is **wasted work**. If the per-cell option
is taken up later, it must be folded into the same revision, not a new one. Conversely, if the wing
is respun for any *other* reason, the bypass diodes are to be folded in at the same time.

### 2.7 Decision item 7 — relationship to ADR-051's per-INTERFACE provision: this REFINES and EXTENDS it; it does NOT supersede it

Stated explicitly, to avoid a silent contradiction:

- **ADR-051 §2.4 decision 4.2** mandates the **per-interface** bypass diodes **populated, not DNP**,
  on any cutter-carrying flight. That per-interface provision **IS the per-group-of-3 case** (§1.5)
  and this record **AFFIRMS it** as the recommended grouping. Net and component names
  (`D_BP1…D_BP4`, `W<n>_SOLAR_P`/`W<n>_SOLAR_N`, cathode to P) are **unchanged**.
- **ADR-051 §2.7** re-rates the diodes to **≥2 A / 40 V** and excludes SOD-323. This record
  **AFFIRMS** that and adds the datasheet-priced part mass (§1.6) and the disqualification of the
  BAT54 as a *fitted* part (§2.2).
- **ADR-051 §2.4 decision 4.3** states the continuous-current rule **for the post-cut case**. This
  record **EXTENDS** that rule from *post-cut* to **post-any-failure-and-during-shading** — i.e. the
  bypass path is permanent for every one of the three failure modes (§1.4), not only after a
  commanded cut. **This is a broadening of ADR-051 §2.4.3, not a contradiction of it.**
- **ADR-051's per-interface provision is refined, not superseded,** because this record agrees with
  its count and adds (i) the per-cell alternative priced, (ii) the extension of the continuous rule
  to all three failure modes, (iii) the placement consequence, and (iv) the mechanical gate.

**Nothing in ADR-051 is superseded by this record.** Where this record and ADR-051 differ in
emphasis, ADR-051's per-interface *count* governs (as the recommendation) and this record's
*extension of the duty rule* governs. They are consistent.

### 2.8 Decision item 8 — a FAIL-CLOSED checker is mandated as a CI gate

**`scripts/bypass_diode_check.py` is a required CI gate.** It reads the v9 schematic/netlist and

- **exits 1 (FAIL)** if any cell or series group in the solar path has **no bypass diode across
  it**, or a diode is across it with the **wrong polarity**, or a bypass position is held by a
  **known under-rated part** (e.g. a BAT54);
- **exits 2 (UNDETERMINED, non-zero)** whenever it **cannot establish the answer** — an unreadable
  or unrecognised input, no solar group found, an unresolvable diode polarity — so it can **never
  silently pass**;
- **exits 0 (PASS)** only when every solar group is covered by a correctly-polarised, adequately
  rated diode.

`tests/test_bypass_diode_check.py` proves the gate **passes a good fixture** and **FAILS
deliberately-bad ones** — including a group with **no diode at all** — so the check's ability to
fail is itself tested (§6, and ADR-051 §2.1.3 for the same doctrine).

## 3. Consequences

### Positive

- **One cracked cell stops being a single point of failure for the array.** With the diode, an open,
  shorted or shaded cell costs one cell (per-cell) or one group (per-group) instead of the whole
  6.0 V string (§1.2, §2.3).
- **The per-group topology is already drawn and costs no new parts beyond the re-rate** — the
  `D_BP1…D_BP4` provision exists; ADR-051 §2.4.2 already mandates its population (§1.5).
- **The rule is now sized on the honest duty cycle** (permanent continuous current, §2.2), which
  retroactively explains why the BAT54 was always wrong and disqualifies it as a *fitted* part.
- **The invariant is machine-checked** with a test that proves the check can fail (§2.8) — the defect
  is caught in CI, not in flight.
- **The per-cell option is priced, not dismissed** (512 mg), so a later decision to buy redundancy
  granularity is informed and the checker already covers it.

### Costs (accepted)

- **Mass, and it is real but small.** Per-group adds **256 mg** of diodes; per-cell adds **768 mg**,
  a **+512 mg** delta (§1.6). On a payload where ADR-049's entire four-wing array is 12.85 g, and
  ADR-051 adds ≈14–20 g, this is bounded but not free.
- **Land/package change on the hub** (SOD-323 → SMA/SMB or leadless 2 A class, §2.2), which re-opens
  the interface land-row layout (ADR-051 §2.7 already records this).
- **A new CI gate to maintain** (§2.8), plus the requirement that it be run at the correct netlist
  path and not allowed to pass on a missing solar path.
- **A wing respin becomes mandatory** (it already was, ADR-051 §2.6) — this record makes the
  consolidation rule explicit so it is paid once (§2.6).
- **The recommendation is conditional** on the pending topology study (§1.6): if that study changes
  the premise, the grouping is re-opened.

## 4. Open items (all explicit, none invented)

1. **The grouping decision — per-cell (12 diodes, 768 mg, 1/12 granularity) versus per-group of 3
   (4 diodes, 256 mg, 1/4 granularity).** Recommendation is per-group; the deciding number is the
   **+512 mg** delta (§1.6, §2.4). **Revisable.**
2. **The exact part.** Named candidates are the **Diodes Inc B240/A** (SMA/SMB, 2.0 A / 40 V —
   **mass verified: 64 mg SMA / 93 mg SMB**, datasheet `ds13004.pdf`) and the Nexperia
   **PMEG4020ER** (SOD123W, 2.0 A / 40 V — **mass `TODO(unverified)`, not stated in its datasheet**).
   Whether the chosen part's **temperature-derated continuous current** clears 1.2 A at altitude/cold
   is **`TODO(unverified)`** (ADR-051 §2.7) — a bench/datasheet task, not decided here.
3. **Whether the hub array (ADR-051 §2.2) also gets per-cell diodes.** If the hub array exists, its
   cells are hub-mounted and need their own diodes; per-cell or per-group there is a fresh trade
   (§2.5). Not decided; the checker handles the case when hub cells appear in the netlist.
4. **The pending `analysis/array-topology-fault-tolerance` topology study may supersede the
   cut-ladder premise.** That branch **does not exist** on `github` as of this writing (§ header).
   If it finds the ARRAY (not the cut) is the right fault-tolerance lever, the **per-cell option
   re-opens** and possibly ADR-051 §2.4's ladder premise with it. **This record does not anticipate
   its result** and marks its own grouping recommendation revisable pending it.
5. **The cracked cell's electrical signature** (open vs. resistive) — observed as a failure but not
   characterised; it decides whether mode 1 or mode 2 dominates (§1.4, §1.9) and is a bench item.
6. **The hub land/package change** forced by the ≥2 A part inside the interface keep-out (ADR-051
   §2.7) — layout, not decided here.

## 5. What would falsify this

- **A bench finding that a cracked cell goes hard-short, never open** → mode 1 does not occur, the
  safety argument weakens to modes 2/3, and the diode's justification is re-priced (the diode is then
  a hot-spot guard, not a string-continuity guard). §1.4 must be amended with the observation.
- **A topology study showing the array must tolerate MULTIPLE simultaneous cracks** → per-group (4
  diodes) is insufficient and the per-cell option is promoted from alternative to requirement
  (§2.4 recommendation reversed).
- **A measured continuous current through a bypassed position materially below 1.2 A** (e.g. because
  of a tap/converter arrangement) → the ≥2 A sizing is over-specified and a smaller part is
  admissible; §2.2's rating is amended with the number.
- **A diode found that carries 1.2 A continuously in a SOD-123-class package** → the package/land
  consequence (§2.2 item 4) softens, though the re-rate from the BAT54 stands.
- **Evidence that the wing respin can be avoided** (e.g. the cut-sense line routed through the
  harness instead of the wing `RF_FEED` land, ADR-051 §2.6) → the §2.6 consolidation premise
  weakens, though consolidating wing changes into one revision remains correct practice.

## 7. Notes

- **Why the number is 053, not 052.** The allocator returned 52 **in this checkout**, but 052 is in
  flight on `adr/cell-mounting-end-only`; the corpus rule (ADR-051/ADR-052 headers) is to check
  across **all branches**, where 053 is the next free. Recorded in the header so the collision cannot
  be mistaken for a defect. This record does not rename anything.
- **Why the diode masses differ from the repo's own.** `docs/PAYLOAD-WEIGHT-ESTIMATES.md` line 36
  gives 15 mg (SOD-123) and `docs/analysis/wing-ladder.md` line 252 gives ~20 mg (SOD-323) / 30 mg
  (SMA) — both explicitly **estimates**, not datasheet figures. This record uses **vendor datasheet**
  masses (B240 SMA = 64 mg) because the sizing hinges on the number and a guess would be worse than
  the estimate it replaces. The estimates remain valid for the SOD-323/SOD-123 class they name.
- **Why the BAT54 is called out even though it is DNP.** A DNP part is a *provision*, and a provision
  with an under-rated part is a latent defect the moment someone fits it. Naming the disqualification
  (§2.2 item 3) and making the checker FAIL on a known under-rated part (§2.8) turns "someone fitted
  the BAT54" from a silent flight risk into a build failure.
- **Why the recommendation is per-group despite the operator asking about "individual cracked
  cells".** The operator asked whether the circuit *can* tolerate individual cracked cells; it
  **can** (per-cell), and this record prices it. But the honest engineering answer is that the
  **per-group** topology already keeps the vehicle charging (§1.6) at **512 mg** less, and on a
  mass-bound payload that is the right default. The record states the number that decides it so the
  operator can overrule the default knowingly.
- **Why the continuous-current rule is written as its own decision item.** It is the difference
  between a valid bypass and an invalid one: a transient-rated part (BAT54) *looks* adequate for
  shading and is catastrophically wrong for a permanent path (§1.3). Prose that says "add a diode"
  without the duty cycle would invite exactly the part that is already in the schematic.
- **Why the checker is fail-closed and mutation-tested.** Same doctrine as ADR-051 §2.1.3: the
  invariant must be able to **fail a build**, and the test must prove it **can** fail, or the gate is
  decoration.
- **No hardware is ordered by this record.** It is design work only.

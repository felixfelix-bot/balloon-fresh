# ADR-054: SKiDL for Netlist Authoring of New Boards

**Date:** 2026-10-13
**Status:** Accepted (evaluate-and-adopt for base-station + bench-rig)
**Decision Maker:** Felix (operator), directive 2026-10-13 ("evaluate SKiDL for authoring the missing boards' schematics")
**Related:** ADR-051 (stage 1 = logical definition), ADR-107 (three-variant design; no .kicad_sch files exist)

## Context

The project has 100+ board variants generated by Python scripts
(`full_pipeline.py` class) with **no schematic files and no ERC ever run**
(ADR-107 context). Netlists live implicitly in placement scripts — the
"schematic → layout" change-flow rule of ADR-051 has nothing to flow FROM.

External guidance (vetted 2026-10-13): SKiDL lets the netlist be written as
pure Python (token-efficient for LLM authoring, reviewable in diffs, and it
compiles to netlists KiCad consumes). This matches the fleet's code-as-CAD
doctrine: LLM writes intent; deterministic tools compile and check.

## Decision

For the two new boards (base-station, bench-rig), stage-1 logical definition
is authored in **SKiDL**:

- `tracker/hardware/<board>/netlist.py` — components, values, connections as
  Python; imports shared subcircuits where reused (radio module, supercap
  charger per ADR-006, FEM per ADR-005).
- Compile to netlist → generate the KiCad board from it; the netlist is the
  single source of truth for connectivity (layout-only edits are forbidden,
  ADR-051 rule).
- ERC runs on the netlist BEFORE placement (a missing-connection class of
  bug is caught at stage 1, the cheapest point).

**Condition (evaluate-first):** if SKiDL's KiCad-9 netlist import proves
lossy for our footprints (castellated antenna pads, RF modules), the
fallback is direct `.kicad_sch` generation via `kicad-cli`/pcbnew scripting
— same principle (netlist-first), different syntax. The evaluation lands
with the base-station board's stage-1 card.

Hub-v9 is NOT retrofitted (frozen too far past stage 1); its netlist truth
remains the board file.

## Consequences

- New boards get ERC coverage for the first time in project history.
- Netlists are diffable, LLM-authorable at ~1/20 the tokens of raw board
  files, and reusable across the three bench-firmware variants
  (BENCH-CONSOLE-SPEC consumers).
